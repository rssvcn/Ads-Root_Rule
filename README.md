# qy-Ads-Root_Rule
适用于 Root 安卓设备的广告拦截域名规则仓，仅兼容 AdGuard 安卓客户端。

## 说明
- 目标：拦截国内APP广告、信息流内嵌广告、卡片广告、埋点追踪域名
- 运行环境：已 Root 的安卓设备（包括临时Root）
- 适配软件：**仅 AdGuard 安卓客户端**
- 更新频率：不定期维护更新
- 规则类型：AdGuard 过滤语法，使用**修饰符**，不兼容 hosts、AdGuard Home、其他DNS过滤器

## 使用方式
1. 打开 AdGuard 安卓客户端 → 过滤器 → 自定义过滤器
2. 添加过滤器，填入本规则原始 raw 链接
3. 启用规则，安装证书 AdGuard HTTPS 过滤（证书已在系统根证书安装，Root环境）
>  重要：未Root设备无法正常使用本规则配套的证书与拦截能力；本规则依赖AdGuard专属修饰符，**无法在 AdGuard Home、hosts、DNSMasq 等平台加载**

## 注意事项
1. 仓库规则使用 AdGuard 专属修饰符，脱离AdGuard安卓客户端会失效
2. 规则仅用于个人学习使用
3. 如遇到APP异常、闪退，可临时关闭对应规则并提交反馈
4. 本规则不支持跳过激励广告、广告拿奖励，有该需求请勿使用、勿入群
